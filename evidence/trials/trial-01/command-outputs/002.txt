# Corrected screening deliveries disagree with stored studies

Operators report that corrected transfer deliveries sometimes reuse earlier evidence, waiting analyses disagree with their submission context, and exported reports omit distinct wells. The supplied incident database also contains studies that still disagree after the live workflow is corrected.

Please investigate and repair the workflow, reconcile the retained evidence safely, and preserve historical results and review provenance. Provide useful regression tests and an executable migration report on a copy of the supplied database. Explain remaining blocked studies in RECOVERY-NOTES.md.
# Runtime

Run with Python and the installed dependencies: `PYTHONPATH=src python -m pytest`. The private checker invokes the documented CLI against independent evidence histories, including malformed and incomplete inputs. It checks observable behavior, preservation, backup, atomicity and repeat safety. No network is available during grading. Keep changes in this checkout; do not access authentication files.
