# Recovery-r4 review criteria

Grade actual command execution, not supplied narrative. Require correct scientific transfer reconstruction; full input identity; dataset-scoped jobs; complete per-well exports; retained-byte recovery; format-compatible decoding; verified adoption of prior recovery; correct publication-based current selection; preserved produced results and immutable evidence; safe backups, whole-apply rollback and repeat behavior.

Use the complete 11r4-full profile. An eight-case focused pass alone does not establish completion. Human review assesses implementation quality, useful tests, operational notes and unresolved evidence. Solver repair cycles and runtime measure difficulty separately and are never correctness requirements.
