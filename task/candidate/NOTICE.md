# Provenance

This repository contains an original, AI-assisted software implementation. Study examples are synthetic measurements, not client records or instrument acquisitions.

The workflow themes were informed by the owner's scientific experience and supplied demonstration material concerning screening, assay comparison, stability, rare populations and controlled records. Existing benchmark solutions, datasets and verifiers were not copied into this repository. Workflow references are not proof of intellectual-property clearance under an external agreement.

The repository is intended to remain private. No public redistribution license is granted by this file. Third-party libraries retain their own licenses. Scientific references are linked in the methods document.
