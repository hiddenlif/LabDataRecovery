# Transfer-history walkthrough

Analyze `initial.json`, then compare `corrected.json`. The corrected measurement of `add-1` changes the early mixture and the later dilution. The separate late addition must not change either earlier readout. These small examples demonstrate reconstruction rather than a sufficiently sampled potency curve.

Use `transfer-preview` to inspect step contents and bindings. Create a screening campaign, import the initial input, submit a job, import the correction, then complete the original job and export both analyses. Existing review and job documentation describes these commands.

The `study.db` and `historical-report` artifacts contain an imported initial study and its analysis for inspection. They are generated by the application. They contain no reference implementation or private checks.

From the application root run `PYTHONPATH=src python examples/transfer-history/reproduce.py /absolute/new-walkthrough-directory`. It copies the persisted study, submits a job, imports the correction, completes the pinned job and exports both histories. The output is calculated by the running application.
